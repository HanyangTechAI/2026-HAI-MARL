## 1. 개요 및 필요성
기존 시뮬레이션 환경에 포함된 `Epsilon Greedy` 모델은 일정한 확률(`epsilon`)로 무작위 탐색을 수행합니다. 그러나 학습 초기에는 정보가 부족하므로 탐색(Exploration)을 많이 해야 하고, 후반부로 갈수록 이미 파악된 정보를 바탕으로 보상을 극대화(Exploitation)해야 합니다. 이를 위해, 시간에 따라 탐색 확률이 줄어드는 **Decaying Epsilon Greedy** 알고리즘을 신규 도입 및 구현했습니다.

## 2. 코드 구현: `agents/decaying_epsilon.py`
강화학습의 유명한 기법 중 하나인 '지수 감쇠(Exponential Decay)' 방식을 사용하여 에이전트 클래스를 구현했습니다.
* **수식**: $ \epsilon_{t} = \max(\epsilon_{min}, \epsilon_{0} \times \gamma^t) $
* **파라미터 설명**:
  * `initial_epsilon`: 학습 초기 탐색 확률 (예: 0.5)
  * `min_epsilon`: 감쇠되더라도 유지해야 할 최소 탐색 확률 (완전히 0이 되는 것을 방지하여 환경 변화에 대응, 예: 0.01)
  * `decay_rate` ($\gamma$): 시간이 흐름에 따라 $\epsilon$이 감소하는 비율 (예: 0.99, 0.995 등)

```python
# 현재 시간에 맞춰 epsilon 감쇠 (지수 감쇠 방식)
self.current_epsilon = max(self.min_epsilon, self.initial_epsilon * (self.decay_rate ** self.t))
```
스텝(`t`)이 지날수록 `self.current_epsilon` 값은 계속 작아지며, 어느 순간 `min_epsilon`에 도달하여 상수 유지 형태가 됩니다.

* **0.995 감쇠율의 압도적 우위**: 고정 $\epsilon=0.05$ 방식이나 Sliding Window UCB를 모두 꺾고 `DecayEps_0.995`가 **전체 1위**를 달성했습니다.

* **결론**: 복잡하게 데이터를 주기로 끊거나 Sliding Window를 복합적으로 사용하는 것보다, 본질적인 **탐색/활용 균형(Exploration & Exploitation) 감쇠 로직 하나를 잘 튜닝하는 것이 종합적인 수익 극대화에 훨씬 유리**할 수 있음을 입증했습니다.
