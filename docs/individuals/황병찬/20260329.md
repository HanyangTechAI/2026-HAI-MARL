## 1. 강화학습 (신경망 모델 X) 알고리즘 2종 학습 및 구현

`main_time.py`에 적용된 환경은 전형적인 MAB (Multi-Armed Bandit) 환경이므로, 이에 가장 적합하고 널리 쓰이는 두 가지 고전 강화학습 알고리즘을 선택해 `docs/individuals/황병찬/` 폴더 산하에 직접 구현하였습니다.

### A. UCB (Upper Confidence Bound) 알고리즘
- **학습 개념**: 강화학습의 최대 난제인 **탐험(Exploration)**과 **활용(Exploitation)**의 균형을 낙관적 탐색(Optimism in the Face of Uncertainty)이라는 수학적 원리로 조절하는 알고리즘입니다.
- **작동 원리**: 선택 횟수가 적어 데이터가 부족한 자산(Arm)에는 '불확실성에 대한 보너스 점수'를 높게 부여하고, 동시에 기본적으로 평균 보상치(Q값)가 높은 자산 역시 선호하는 방식입니다.
  - $UCB = Q(a) + c \times \sqrt{\frac{\ln(t)}{N(a)}}$
- **구현 파일 경로**: `docs/individuals/황병찬/ucb.py`

### B. Softmax (Boltzmann Exploration) 알고리즘
- **학습 개념**: Epsilon-Greedy 알고리즘이 '탐험 시 아무 곳이나 무조건 무작위로 간다'는 무식함을 개선하기 위해, **Q-Value(기대 보상)에 비례하여 확률적으로 선택지**를 고르는 알고리즘입니다.
- **작동 원리**: Softmax 함수를 사용하여 Q값이 높은 자산이 선택될 확률을 기하급수적으로 높이고, Q값이 낮더라도 약간의 선택될 확률은 유지하여 부드러운 확률적 탐험을 유도합니다. (온도, Temperature 파라미터로 무작위도의 정도를 조절)
- **구현 파일 경로**: `docs/individuals/황병찬/softmax.py`

## 3. 알고리즘 실험 결과 및 분석 인사이트

월마트 환경 데이터(1941 Steps, 보상 0.0001 스케일링, Event Shock이 포함된 동적 환경)를 바탕으로 두 차례 모델 성능 평가를 진행한 결과입니다.

### 1차 실험 (기본 파라미터 적용)
- **설정**: `UCB (c=1.0)`, `Softmax (Temperature=0.1)`
- **결과**: 두 알고리즘 모두 총 누적 보상 측면에서 최하위권(약 480~490점)을 기록했습니다.
- **분석**: "최적 자산(답)"을 고르는 비율은 34~45%로 준수했으나, 스케일링이 작게 된 환경에서 `c=1.0`의 UCB는 최적 자산을 찾은 이후에도 다른 안 좋은 자산에 계속 과도한 탐험(Over-exploration)을 지속했습니다. 반면, 10%의 확률로 적절히 탐험하는 `Epsilon-Greedy (eps=0.1)` 모델이 압도적인 1위(총 보상 약 702점, 최적 자산 선택 91%)를 차지해 1차 실험의 승자가 되었습니다.

### 2차 실험 (하이퍼파라미터 튜닝 적용)
- **수정된 설정**: `UCB (c=0.01)`, `Softmax (Temperature=0.01)` (탐험 빈도를 극도로 낮춤)
- **결과**: 두 알고리즘 모두 **최적 자산 확률 추적률 99.8% ~ 100%라는 완벽한 수렴(Convergence)**에 도달했습니다.
- **핵심 인사이트 (기계의 정답 vs 현실의 잭팟)**:
  - 파라미터 튜닝 후, UCB와 Softmax는 수학적으로 평균 기대치가 가장 높은 정답(Arm 2)을 완벽하게 찾아내어 고정적으로 채굴하는 강력한 "Exploitation(활용)" 능력을 입증했습니다.
  - 하지만 흥미롭게도 전체 탐험 확률이 가장 적었던 `Epsilon-Greedy (eps=0.05)` 모델이 역설적이게도 1위(약 792점, 정답 선택률 0.9%)를 차지했습니다.
  - 이는 이번 테스트 대상 기간(1941일) 동안 특정 비주류 자산에서 엄청난 폭등(Event Shock)이 터졌고, Epsilon 모델이 우연히 단기적 폭등에 탑승해 점수를 쓸어 담았기 때문으로 분석됩니다.
- **결론**: 이번 테스트를 통해 UCB와 Softmax 알고리즘 모델의 훌륭한 정답 수렴 능력을 확인하였고, 파라미터(Hyperparameter) 튜닝과 현실의 단기적 예외 사항(Shock) 포착이 결과에 미치는 막대한 영향을 직접 체험할 수 있었습니다.
