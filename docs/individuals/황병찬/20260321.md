## DQN 핵심 개념

**① Experience Replay**
> Replay Buffer에 경험을 쌓고, 미니배치(100개)씩 랜덤 샘플링하여 학습

**② Target Network 분리**
> Q-network와 Target network를 별도로 두어 학습 안정성 확보

---

## 학습 루프 (dqn.py 핵심 흐름)

```
1. Replay Buffer에서 미니배치 샘플링
2. Target network로 다음 Q값 계산 (greedy → max값 선택)
3. TD Target 계산
   - 에피소드 종료 시: reward만
   - 진행 중: reward + γ × max Q(s')
4. Q-network로 현재 Q값 계산
5. Huber Loss 계산 → 역전파 → 파라미터 업데이트
```

---

## 정리

> DQN = Q-learning + **Experience Replay** + **Target Network**

이 두 가지 기법 덕분에 딥러닝 기반의 안정적인 강화학습이 가능해짐
