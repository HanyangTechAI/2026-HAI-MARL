## MARL 시뮬레이터 구축을 위한 초기 환경 세팅

### 1. 프로젝트 초기 환경 셋업
- Conda 가상환경 구성을 위한 `environment.yml` 작성 및 라이브러리 버전 고정 (Python 3.10)
- 데이터 로그(`.csv`)와 그래프 이미지(`.png`) 용량 폭발 방지를 위한 `.gitignore` 셋팅 완료
- 팀 협업을 위한 6대 깃허브 커밋 컨벤션(`add`, `mod`, `fix`, `docs`, `del`, `chore`) 수립 및 공유 준비

### 2. 시뮬레이터 코어 엔진 구축
- **SMPyBandits 경량화**: 원본 라이브러리의 무거운 통신/시각화 로직을 제외하고, 금융 도메인 모사에 필수적인 모듈만 `envs/SMPyBandits/` 폴더로 이식 완료.
  - *적출 완료 파일:* `Arm.py`, `Gaussian.py`, `RestlessArm.py`, `MAB.py`, `CollisionModels.py`
- **커스텀 평가기(`custom_evaluator.py`) 개발**: 다중 에이전트의 충돌을 감지(np.bincount)하고 슬리피지(Slippage) 보상 삭감을 적용하는 메인 심판 로직 뼈대 완성.
- **Base Agent (`base_agent.py`) 설계**: DS/IE 팀원들이 알고리즘 수식(`choice()`) 작성에만 집중할 수 있도록, Q-value와 누적 보상 메모리를 자동 업데이트하는 공통 부모 클래스 설계 완료.


## Trouble Shooting
### Issue 1: `plotsettings` 및 `pykov` 모듈 Import Error
- **원인:** 환경(MAB) 로드 시, 원본 라이브러리에 묶여있던 무거운 시각화(`plotsettings`) 및 마르코프 체인(`pykov`) 로직을 호출하려다 에러 발생.
- **해결:** 시각화는 추후 분석 단계에서 `seaborn`으로 직접 처리하기로 기획했으므로, `MAB.py` 상단의 해당 `try-except` 임포트 블록을 과감히 주석 처리하여 코드 다이어트 진행.

### Issue 2: 가짜 `kullback.py` (Symlink) 로 인한 연쇄 SyntaxError
- **원인:** 깃허브에서 `kullback.py`를 다운받았으나, 실제 코드가 아닌 리눅스 심볼릭 링크(바로가기) 텍스트 파일로 파싱되어 `SyntaxError` 발생. 이로 인해 `Arm.py` 연쇄 임포트 실패.
- **해결:** 불필요한 KL-Divergence 수학 연산 모듈(`kullback`)을 파일 시스템에서 완전히 삭제하고, `Gaussian.py` 내의 의존성 코드를 `from .Arm import Arm` 한 줄로 깔끔하게 수정.

### Issue 3: `MAB.py` 초기화 시 `lowerbound` 연산 에러
- **원인:** `MAB` 객체 생성 시, 이론적 수학 하한선(Lai & Robbins complexity)을 터미널에 출력(`print`)하려 시도했으나 내부 연산 모듈 부재로 `NotImplementedError` 발생.
- **해결:** `MAB.py` 내부의 불필요한 `print` 디버깅 코드를 입틀막(주석 처리)하여 시뮬레이터가 오직 '수익률 반환' 기능에만 집중하도록 무력화 성공.
