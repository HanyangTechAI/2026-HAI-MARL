# 📅 개발 일지: 2026-03-29
**주제: 실제 유통 데이터 기반 다이내믹 환경 구축 및 MLOps 자동화 파이프라인 완성**

## 🚀 1. 핵심 성과 요약
과거의 정적(Stationary) 수학 모델을 버리고, 월마트 M5 실제 데이터를 기반으로 '주기성(Seasonality)'과 '돌발 충격(Shock)'이 공존하는 **현실적인 Non-stationary MARL 전장**을 완성함. 또한 시뮬레이션 실행부터 결과 시각화까지의 전 과정을 **원클릭 자동화(End-to-End Automation)** 함.

---

## 🏗️ 2. 아키텍처 및 환경(Environment) 고도화

### 2.1. 데이터 기반 특징 추출 자동화 (`feature_extractor.py`)
* 단순 Z-Score 대신 산업 표준인 **STL(시계열 분해) + IQR 기법**을 도입하여 현실적인 '돌발 충격(Shock)'을 정밀하게 탐지.
* `sales_train_evaluation.csv`를 읽어 21개 전체 매대의 파라미터를 한 번에 추출.
* **추출 산출물 (`data/walmart/extracted_data/`):**
  1. `base_params_registry.csv`: 각 Arm의 평소 평균, 분산, 트렌드(기울기)
  2. `seasonality_registry.csv`: 요일별(0~6) 수요 파동 배수(Multiplier)
  3. `shocks_registry.csv`: 특정 스텝에 발생하는 극단적 폭증/폭락 배수(Multiplier)

### 2.2. Registry 패턴 도입 (`arms/arm_registry.py`)
* **관심사의 분리(Separation of Concerns):** 메인 실행 파일(`main_time.py`)에 하드코딩되던 환경 파라미터를 레시피 북(`Registry`)으로 분리.
* 시뮬레이션을 돌릴 때 레지스트리에 등록된 텍스트 이름(예: `"CA_FOODS_3"`)만 호출하면 팩토리(Factory) 패턴으로 자동 조립됨.

## ⚙️ 3. MLOps 로깅 및 시뮬레이션 파이프라인 (`main_time.py`)

### 3.1. 체계적인 로깅(Logging) 시스템
* `logging` 모듈을 연동하여 터미널 실시간 출력(StreamHandler)과 파일 저장(FileHandler)을 동시 지원.
* 매 실행마다 `output/YYYYMMDD_HHMMSS/` 형태의 독립된 타임스탬프 폴더를 생성하여 실험 결과를 덮어쓰기 없이 영구 보존.
* `experiment.log`를 통해 시뮬레이션의 모든 과정을 기록.

### 3.2. 보상 정규화 및 스케일링
* 신경망/알고리즘의 계산 폭발(Exploding)을 막기 위해 `GLOBAL_SCALER = 0.0001`을 적용하여 보상을 [0, 1] 스케일로 압축하여 학습시킴.
* 분산(Variance) 적용 시 스케일러의 제곱(`** 2`)을 곱하는 수학적 정합성 확보.

## 📊 4. 시각화(Visualization) 자동화 (`utils/plot_results.py`)

시뮬레이션 루프 종료 직후 자동으로 호출되며, 정규화된 보상 데이터를 원래 스케일(x 10000)로 역변환하여 인간 친화적인 그래프를 자동 생성함.

### 4.1. 거시적 시장 분석 (Macro Metrics)
* **`fig1_cumulative_rewards.png`:** 전체 기간 동안의 에이전트별 누적 보상 수익 비교.
* **`fig2_moving_averages_10_50_100.png`:** 10일/50일/100일 3중 이동평균(MA)을 Subplot으로 제공하여, 단기 충격 적응력과 장기 트렌드 안정성을 동시 평가.
* **`fig3_collision_trend.png`:** 에이전트 간의 겹침(Collision) 현상을 추적하여 시장의 '슬리피지(Slippage)' 강도 시각화.

### 4.2. 에이전트별 미시적 행동 분석 (Micro Analysis)
* 에이전트 이름으로 개별 하위 폴더 생성.
* **Action Pie Chart:** 전체 시뮬레이션 동안 해당 에이전트가 어떤 라인(Arm)에 주로 투자했는지 파이 차트로 요약.
* **Action Transition (100-Day Stacked Area Chart) [★논문 핵심]:** 에이전트의 '선택 확률 변화'를 누적 영역 그래프로 표시. 충격(Shock)이 발생했을 때 에이전트가 기존 라인을 버리고 새로운 라인으로 갈아타는 **'적응(Adaptation) 과정'**을 직관적으로 증명.
