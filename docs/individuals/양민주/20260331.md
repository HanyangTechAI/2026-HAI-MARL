### A. Thompson Sampling (톰슨 샘플링)
- **학습 개념**: 베이지안(Bayesian) 접근법을 사용하는 밴딧 알고리즘입니다. 각 arm의 보상 분포를 Beta 분포로 모델링하고, 매 스텝마다 샘플링하여 가장 높은 arm을 선택합니다.
- **작동 원리**: 
  - 각 arm마다 Beta(α, β) 분포를 유지 (초기값: Beta(1,1) = 균등분포)
  - 매 스텝: 각 arm에서 Beta(α, β) 샘플링 → 가장 높은 값의 arm 선택
  - 보상 수신: 높은 보상 → α 증가, 낮은 보상 → β 증가
  - 탐험/활용 균형이 자동 조절됨 (많이 선택한 arm은 분포가 좁아지고, 적게 선택한 arm은 분포가 넓어서 가끔 높은 값이 나옴)
- **추가 기능**: 비정상 환경 대응을 위한 슬라이딩 윈도우(`window_size`) 옵션 구현
- **구현 파일 경로**: `docs/individuals/양민주/thompson_sampling.py`

### B. EXP3 (Exponential-weight algorithm for Exploration and Exploitation)
- **학습 개념**: **Adversarial(적대적) 환경**에 특화된 밴딧 알고리즘입니다. 보상 분포에 대한 가정이 전혀 없어서, 환경이 어떻게 변하든(트렌드, 이벤트 쇼크, 국면 전환 등) 이론적으로 보장된 성능을 가집니다.
- **작동 원리**:
  - 각 arm에 가중치(weight)를 부여하고, 가중치에 비례한 확률로 선택
  - 균등 탐험 비율(gamma)을 혼합하여 특정 arm에 몰리는 것을 방지
  - **Importance Weighting**: 받은 보상을 선택 확률로 나눠서 보정 → 적게 선택된 arm의 보상이 과소평가되는 것을 방지
  - 보정된 보상으로 가중치를 지수적(exponential)으로 업데이트
- **이 환경에 적합한 이유**:
  - 보상 분포 가정이 없어서 비정상 환경(트렌드, 쇼크, 국면 전환)에 자연스럽게 적응
  - gamma에 의한 균등 탐험이 슬리피지(충돌 패널티) 회피에 유리
  - 확률적 선택이라 다른 에이전트와 행동이 분산됨
- **구현 파일 경로**: `docs/individuals/양민주/exp3.py`

## 3. 알고리즘 실험 결과 및 분석

월마트 환경 데이터(1941 Steps, 보상 0.0001 스케일링, 동적 환경)를 바탕으로 Thompson Sampling과 EXP3의 성능 평가를 진행한 결과입니다.

### 실험 설정
- Horizon: 1941 스텝 (월마트 5년치 일일 데이터)
- Arm 8개: Stationary×2, EventShock×2, Trend×2, Switch×2
- 에이전트 15개 동시 경쟁 (기존 9개 + Thompson 2개 + EXP3 4개)
- GLOBAL_SCALER: 0.0001 / Seed: 66

| 순위 | 에이전트 | 총 보상 | 비고 |

### Thompson vs EXP3 직접 비교

| 항목 | Thompson (기본) | EXP3 (γ=0.2, 최고) |
|------|----------------|---------------------|
| 총 보상 | 101.18 (7위) | 97.05 (11위) |
| 순위 | WSLS보다 위 | Softmax와 비슷 |

**결론: Thompson Sampling이 EXP3보다 이 환경에서 더 나은 성능을 보였다.**

Thompson이 EXP3보다 나은 이유:
- Thompson은 Beta 분포를 통해 각 arm의 보상 정보를 직접 모델링하므로, 확률적(stochastic) 보상 환경에서 정보 효율이 높다.
- EXP3는 adversarial 환경에 대한 worst-case 보장을 위해 설계되어, 확률적 환경에서는 보수적으로 행동하는 경향이 있다. Importance Weighting이 작은 스케일(0~0.2)에서 가중치 업데이트를 불안정하게 만들 수 있다.
- EXP3의 gamma가 높을수록(0.2) 균등 탐험이 많아져 슬리피지 회피에는 유리하지만, 좋은 arm을 집중 활용하는 능력이 떨어진다.

### 전체 분석 및 자가 피드백

**두 알고리즘 모두 UCB/Epsilon-Greedy에 밀린 이유:**
1. **스케일 문제**: 환경 보상이 0~0.2 수준으로 매우 작아서, Thompson의 Beta 분포와 EXP3의 Importance Weighting 모두 비효율적으로 작동. UCB와 Epsilon-Greedy는 Q-value 기반이라 스케일에 덜 민감.
2. **에이전트 과밀**: 15개 에이전트가 8개 arm을 두고 경쟁하면서 슬리피지(1/N^1.5)가 심화. 에이전트 수가 적었던 이전 실험(11개)보다 전체적으로 보상이 낮아짐.
3. **Epsilon-Greedy의 역전**: 에이전트가 많아지자 UCB 대신 Epsilon-Greedy(ε=0.2)가 1위. 과밀 환경에서는 적당한 무작위 탐험이 오히려 충돌을 피하는 데 유리한 것으로 보임.

### 개선 방향
- Thompson: 보상 스케일 보정 (min-max 정규화로 Beta 분포 업데이트 효율 개선)
- EXP3: 보상 스케일에 맞게 Importance Weighting 보정, 또는 EXP3.P(prediction 변형) 적용 검토
- 공정 비교를 위해 에이전트 수를 줄여서(Thompson vs EXP3 단독) 슬리피지 없이 순수 성능 비교 필요
- 윈도우 크기 다양화 (Thompson W500, W1000 등)

## 4. 2차 실험: 하이퍼파라미터 튜닝 (보상 스케일 보정)

황병찬님이 UCB의 c를 1.0→0.01로 낮춰서 극적으로 개선한 것처럼, 보상 스케일 문제를 직접 해결하는 `reward_scale` 파라미터를 도입하여 재실험하였습니다.

### 핵심 아이디어
환경 보상이 0~0.2 수준으로 매우 작아서 Beta 분포와 EXP3 가중치 업데이트가 비효율적이었음.
→ `reward_scale`로 보상을 증폭한 뒤 [0,1]로 클리핑하여 분포 업데이트 효율을 개선.

### 실험 설정
- 기존 에이전트 4개 (Eps 0.05, Eps 0.1, UCB 0.1, WSLS) + Thompson/EXP3 변형 9개
- Thompson: reward_scale = 1(기존), 3, 5, 7 / window_size = 500
- EXP3: gamma = 0.02, 0.05, 0.1 / reward_scale = 1(기존), 5

### 2차 실험 결과

| 순위 | 에이전트 | 총 보상 | 비고 |
|------|----------|---------|------|
| 1 | Epsilon-Greedy (ε=0.05) | 192.73 | |
| 2 | Epsilon-Greedy (ε=0.1) | 171.99 | |
| 3 | **Thompson (x7)** | **135.89** | ★ 스케일 보정 |
| 4 | UCB (c=0.1) | 131.32 | |
| 5 | **Thompson (x5, W500)** | **129.55** | ★ 스케일 + 윈도우 |
| 6 | **Thompson (x5)** | **126.89** | ★ 스케일 보정 |
| 7 | **Thompson (x3)** | **122.53** | ★ 스케일 보정 |
| 8 | **EXP3 (γ=0.05, x5)** | **112.29** | ★ 스케일 보정 |

### 2차 실험 분석

**Thompson Sampling 스케일 보정 효과:**
- reward_scale=7로 보정한 Thompson이 **UCB(c=0.1)를 제치고 3위**까지 상승. 기존(x1) 대비 약 22% 성능 향상.
- 스케일이 높을수록 Beta 분포의 α/β 업데이트가 의미 있는 크기로 이루어져 arm 간 차이를 더 빠르게 학습.
- 윈도우(W500) + 스케일(x5) 조합도 5위로 준수. 비정상 환경 적응과 스케일 보정을 동시에 적용한 결과.

**EXP3 스케일 보정 효과:**
- reward_scale=5 적용 시 기존(x1) 대비 약 6% 개선. Thompson만큼 극적이지는 않음.
- gamma=0.05가 가장 좋은 성적. 너무 낮은 gamma(0.02)는 탐험 부족, 너무 높은 gamma(0.1)는 탐험 과잉.

**Thompson vs EXP3 최종 비교:**
- 모든 조건에서 Thompson이 EXP3보다 우수. 이 환경은 확률적(stochastic) 보상이므로 베이지안 접근(Thompson)이 adversarial 접근(EXP3)보다 정보 효율이 높음.
- EXP3는 보상 분포가 적대적으로 변하는 극단적 환경에서 강점이 있지만, 이 월마트 환경은 그 정도까지는 아님.
