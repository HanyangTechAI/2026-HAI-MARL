# 2026-04-16 실험 기록: Contextual Bandit 알고리즘 구현 및 성능 평가

## 📋 실험 목적

Multi-Armed Bandit 문제에서 **contextual information**(시간, 요일, 계절성, 충격 이벤트 등)을 활용하여 기존 알고리즘(Epsilon Greedy, UCB 등)보다 우수한 성능을 내는 알고리즘을 개발하고 검증한다.

## 🎯 구현 알고리즘

### 1. LinUCB (Linear Upper Confidence Bound)
- **핵심 아이디어**: Ridge Regression + UCB
- **특징**:
  - 각 arm에 대해 독립적인 선형 모델 학습
  - Context feature를 활용하여 보상 예측
  - L2 regularization으로 안정성 확보
  - UCB 방식으로 탐색-활용 균형

- **수식**:
  ```
  θ_a = A_a^{-1} * b_a  (Ridge regression solution)
  UCB_a = θ_a^T * x + α * sqrt(x^T * A_a^{-1} * x)
  ```

- **파라미터**:
  - `alpha`: exploration parameter (1.0, 0.5 테스트)
  - `lambda_reg`: L2 regularization (1.0)

### 2. Lasso Bandit
- **핵심 아이디어**: Lasso Regression (L1 regularization) + UCB
- **특징**:
  - Feature selection 효과 (중요한 feature만 선택)
  - Elastic Net (L1 + L2) 사용
  - Gradient descent로 학습
  - 주기적으로 전체 히스토리로 재학습

- **파라미터**:
  - `alpha`: exploration parameter (1.0)
  - `lambda_l1`: L1 regularization (0.1, 0.05 테스트)
  - `lambda_l2`: L2 regularization (1.0)
  - `learning_rate`: 0.01

## 🔧 Context Features (총 11차원)

### 1. 시간 정보 (5차원)
- `normalized_time`: t / 1941
- `sin(2π * day_of_week / 7)`: 주간 주기성
- `cos(2π * day_of_week / 7)`: 주간 주기성
- `sin(2π * week / 52)`: 연간 주기성
- `cos(2π * week / 52)`: 연간 주기성

### 2. 계절성 정보 (1차원)
- `seasonality_multiplier`: 해당 arm의 요일별 판매 배수

### 3. Arm 고유 특성 (3차원)
- `base_mean / 10000`: 정규화된 평균 판매량
- `slope`: 트렌드 기울기
- `base_variance / 100000`: 정규화된 분산

### 4. 최근 충격 정보 (2차원)
- `has_recent_shock`: 최근 7일 내 충격 여부 (0 or 1)
- `shock_strength`: 충격 강도 (-1 ~ 1)

## 📊 실험 설정

### Environment
- **Horizon**: 1,941 steps (Walmart 데이터 5년치)
- **Arms**: 4개 (다양한 특성의 매장)
  1. **CA_HOBBIES_1** (Stationary): 안정적인 평균 보상

  3. **WI_FOODS_2** (Trend): 장기 상승 트렌드
  4. **TX_HOUSEHOLD_2** (Switch): 국면 전환형

2. **Epsilon Greedy (ε=0.1)**: 10% 탐색
3. **UCB (c=0.1)**: Upper Confidence Bound
4. **Softmax (τ=0.1)**: 확률적 선택
5. **WSLS**: Win-Stay-Lose-Shift

#### Contextual Bandit 알고리즘 (신규)
6. **LinUCB (α=1.0)**: 높은 탐색
7. **LinUCB (α=0.5)**: 낮은 탐색
8. **Lasso Bandit (λ₁=0.1)**: 강한 L1 regularization
9. **Lasso Bandit (λ₁=0.05)**: 약한 L1 regularization

### 제외된 알고리즘
- Thompson Sampling 계열 (3개)
- Sliding Window UCB 계열 (3개)

## 🔬 예상 결과

### LinUCB의 강점
✅ **요일별 패턴 학습**: 주말 vs 평일 판매 패턴 활용
✅ **트렌드 적응**: 상승/하락 트렌드를 feature로 학습
✅ **충격 이벤트 대응**: 최근 충격 정보를 활용한 예측
✅ **Non-stationary 환경**: 시간에 따른 변화 적응

### Lasso Bandit의 강점
✅ **Feature Selection**: 중요한 feature만 선택하여 과적합 방지
✅ **해석 가능성**: 어떤 feature가 중요한지 명확히 파악
✅ **고차원 데이터**: Feature가 많을 때 효과적

## 🔍 결과 분석

### ❌ Contextual Bandit의 예상 밖 저조한 성능

**LinUCB와 Lasso Bandit이 기존 알고리즘보다 현저히 낮은 성능을 보임**

#### 가능한 원인 분석:

1. **Cold Start 문제**
   - Contextual 알고리즘은 초기에 충분한 데이터가 필요
   - 각 arm별로 독립적인 모델을 학습하므로 초기 학습 기간이 김
   - 1,941 스텝이 충분하지 않을 수 있음

2. **Feature Engineering 부족**
   - 현재 11개 feature가 실제 보상 예측에 충분하지 않을 수 있음
   - Feature 간 상호작용(interaction)을 고려하지 않음
   - 비선형 관계를 선형 모델로 근사하는 한계

3. **하이퍼파라미터 미조정**
   - `alpha` (exploration parameter)가 너무 높거나 낮을 수 있음
   - `lambda_reg` (regularization)이 과도하게 설정되었을 가능성
   - Learning rate가 부적절할 수 있음

4. **Context의 실제 유용성 문제**
   - 추출한 context feature가 실제 보상과 강한 상관관계가 없을 수 있음
   - 시간, 요일 정보가 이 환경에서는 예측력이 낮을 수 있음
   - Walmart 데이터의 계절성이 이미 arm 자체에 내재되어 있을 수 있음

5. **모델 복잡도 vs 데이터 양**
   - 11차원 feature space에서 각 arm당 평균 485회 선택 (1941/4)
   - Ridge/Lasso regression을 학습하기에 데이터가 부족할 수 있음
   - 과적합(overfitting) 발생 가능성

### ✅ 기존 알고리즘의 우수한 성능

**Epsilon Greedy와 UCB가 여전히 최고 성능**

1. **Epsilon Greedy (ε=0.05)**
   - 단순하지만 효과적인 탐색-활용 균형
   - 충분한 탐색으로 최적 arm 발견
   - Context 없이도 안정적인 성능

2. **UCB (c=0.1)**
   - 최종 100 스텝에서 1위 (수렴 성능 최고)
   - 불확실성 기반 탐색이 효과적
   - 시간이 지날수록 성능 향상

3. **Epsilon Greedy (ε=0.1)**
   - 더 많은 탐색으로 다양한 arm 경험
   - 총 보상은 ε=0.05보다 약간 낮지만 여전히 우수

### 📉 성능 차이의 의미

- **1위 vs 6위**: 113.87 vs 44.37 = **2.57배 차이**
- **1위 vs 9위**: 113.87 vs 34.00 = **3.35배 차이**

→ Contextual Bandit이 오히려 성능을 크게 저하시킴
