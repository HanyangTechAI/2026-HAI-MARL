# Thompson Sampling 알고리즘 구현 및 실험
**Date:** 2026-04-08
**Author:** 양민주

---

## 실험 개요

이번 주에는 Thompson Sampling 알고리즘을 활용해서, 주기적 패턴을 분리해서 학습하는 모델과 충돌을 인식하는 모델을 만들어보았습니다. 

월마트 데이터는 주말과 평일의 소비 패턴이 다를 것으로 예상되어, 주말(토,일)과 평일(월~금)로 나누어서 각각 어떤 보상을 받았는지를 분리해서 선택지를 정리해보도록 했습니다. 여기에 충돌 인식 방식도 추가해서 실험을 해보았습니다.

실험 결과, 기본 Thompson Sampling보다는 성능이 좋았고, 특정 조건에서는 Epsilon-Greedy 모델을 제치고 1위를 달성하기도 했습니다.

---

## 구현한 알고리즘

### 1. Thompson Sampling (기본)
- **원리**: 베이지안 접근법으로 각 arm의 보상 분포를 Beta 분포로 모델링
- **특징**: 확률적 탐험으로 탐험/활용 균형 자동 조절
- **파라미터**: `reward_scale` (보상 스케일 조정)

### 2. Thompson Weekend/Weekday (주말/평일 분리)
- **원리**: 주말과 평일을 별도 Beta 분포로 학습
- **특징**: 월마트 데이터의 주기적 패턴 활용
- **효과**: 타이밍 차별화로 다른 에이전트와 충돌 회피

### 3. Thompson Collision Aware (충돌 인식)
- **원리**: 실제 보상이 기대보다 낮으면 충돌로 판단하고 해당 arm 회피
- **특징**: 명시적 충돌 회피 로직
- **효과**: 과밀 환경에서 안정적 성능

## 실험 결과

### 실험 2: 주말/평일 Thompson (7명 경쟁)

| 순위 | 에이전트 | 총 보상 |
|------|----------|---------|
| 1 | **Thompson_x7** | **249.37** |
| 2 | Eps_0.2 | 246.60 |
| 3 | **Thompson_Weekend** | **236.96** |
| 4 | Eps_0.1 | 219.76 |
| 5 | UCB_0.1 | 193.08 |

**결과**: Thompson_x7이 1위, Thompson_Weekend가 3위를 달성했습니다. 주말과 평일 분리 전략이 타이밍 차별화를 통해 충돌을 효과적으로 회피했습니다.

### 실험 3: 충돌 인식 Thompson (8명 경쟁)

| 순위 | 에이전트 | 총 보상 |
|------|----------|---------|
| 1 | Eps_0.05 | 248.57 |
| 2 | UCB_0.15 | 233.59 |
| 3 | **Thompson_CollisionAware** | **201.53** |
| 4 | UCB_0.1 | 197.02 |
| 5 | Eps_0.2 | 187.96 |

**결과**: Thompson_CollisionAware가 3위를 달성했습니다. 에이전트가 8명으로 늘어나면서 충돌 인식 로직이 효과적으로 작동했습니다.

### 실험 4: 다양한 Thompson (10명 경쟁)

| 순위 | 에이전트 | 총 보상 |
|------|----------|---------|
| 1 | UCB_0.1 | 223.89 |
| 2 | **Thompson_CollisionAware** | **201.16** |
| 3 | **Thompson_x5** | **181.15** |
| 4 | Eps_0.2 | 173.12 |
| 5 | Thompson_x10 | 172.42 |

**결과**: 10명 과밀 경쟁에서도 Thompson_CollisionAware가 2위, Thompson_x5가 3위를 달성했습니다. reward_scale=5가 가장 균형잡힌 성능을 보였습니다.

## 분석

### 성공 요인
1. **주말/평일 분리**: 주기적 패턴을 활용하여 타이밍 차별화 → 충돌 회피
2. **충돌 인식**: 실제 보상이 낮으면 해당 arm 회피 → 과밀 환경에서 안정적
3. **reward_scale 튜닝**: 작은 보상(0~0.2)을 증폭하여 Beta 분포 학습 효율 극대화

### Epsilon-Greedy와의 비교
- **Thompson의 장점**: 확률적 탐험으로 정보 효율이 높음. 탐험 공간이 넓을수록(8개 arm) 유리
- **Epsilon-Greedy의 장점**: 단순하고 안정적. 과밀 환경에서 무작위 탐험이 충돌 회피에 유리
- **결론**: 조건에 따라 Thompson이 Epsilon-Greedy를 제칠 수 있음 (특히 arm이 많고 경쟁이 적당할 때)

### 한계점
- 에이전트가 너무 많아지면(10명 이상) 충돌이 심해져서 기본 Thompson은 성능 하락
- reward_scale이 너무 높으면(10 이상) 과적합 발생
- 주말/평일 분리는 에이전트 수가 적을 때(7명) 가장 효과적
