## Conda 가상환경 생성 명령어
conda env create -f environment.yml

## Commits Rule
### add:
새로운 파일, 클래스, 라이브러리, 기능 등 처음 제작했을 때
### update:
기존에 있던 코드의 구조 또는 파라미터 value를 수정할 때
### fix:
문제가 있던 코드를 수정할 때
### remove:
더 이상 쓰지 않는 함수 또는 파일을 제거할 때
### docs:
docs 폴더 내의 작업, 코드 주석 수정했을 때
### chore:
패키지 또는 시스템 관련 수정사항이 있을 때
