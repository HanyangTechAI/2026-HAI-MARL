# 🏆 MARL Benchmark Arena 사용 매뉴얼 (`main_benchmark.py`)

이 스크립트는 다중 에이전트 강화학습(MARL) 모델의 성능을 논문 수준의 엄밀한 통제 환경에서 평가하기 위한 마스터 벤치마크 툴입니다. CLI(Command Line Interface) 파라미터를 통해 코드를 수정하지 않고도 다양한 형태의 실험을 설계할 수 있습니다.

## ⚙️ 1. 기본 설정 파라미터 (Core Settings)
시뮬레이션의 규모와 재현성(Reproducibility)을 통제합니다.

* **`-n` 또는 `--iters`** (int, 기본값: 10)
  * 몬테카를로 평행우주(Seed) 반복 횟수입니다. 
  * 간단한 로직 테스트 시에는 `10`, 최종 논문 통계 추출 시에는 `100` 이상을 권장합니다.
* **`-t` 또는 `--horizon`** (int, 기본값: 1941)
  * 1회 시뮬레이션의 최대 스텝 수(Time Horizon)입니다.
* **`--seed`** (int, 기본값: None)
  * 마스터 난수 시드입니다. 이 값을 고정하면(예: `--seed 42`) 언제 돌려도 100% 동일한 시장 환경과 동일한 난수 결과를 얻습니다. 알고리즘 간의 미세한 성능 차이를 증명할 때 필수적입니다.

## 🌍 2. 시장 환경 파라미터 (Market Environment)
에이전트들이 던져질 생태계의 난이도와 특성을 결정합니다.

* **`-s` 또는 `--market_strategy`** (str, 기본값: "balanced")
  * **`balanced`**: 국밥, 파동, 트렌드, 스위치 4가지 매장 타입을 2개씩 공평하게 차출합니다. (표준 벤치마크)
  * **`random`**: 타입에 상관없이 무작위로 8개를 뽑습니다.
  * **`stationary_only`**: 변동성이 없는 가장 평온한 시장 (탐색보단 수렴 속도 테스트).
  * **`shocks_only`**: 주말마다 요동치는 파동형 시장 (주기성 대응력 테스트).

## ⚔️ 3. 리그 및 에이전트 파라미터 (Agent & League)
어떤 룰(Mode)로 누구를 싸우게 할지 결정합니다.

* **`-m` 또는 `--mode`** (str, 기본값: "baseline")
  * **`baseline`**: 도전자 1명과 고정된 기준군 7명을 싸우게 하여 절대 성능을 평가합니다.
  * **`density`**: 에이전트 수를 극단적으로 늘려 슬리피지(Slippage) 지옥을 만든 뒤, 회피력을 평가합니다.
  * **`custom`**: 팀원들이 만든 여러 에이전트를 한 번에 넣고 자유 난투극을 벌입니다.
* **`-c` 또는 `--challenger`** (str)
  * 평가할 핵심 모델의 이름을 팩토리 명명 규칙에 맞게 입력합니다.
  * *예시:* `SW_AS_UCB_w100_p7_s10.0_c0.05`
* **`-b` 또는 `--baselines`** (str)
  * `baseline` 모드에서 사용될 7명의 샌드백/경쟁자 명단입니다. (띄어쓰기 없이 쉼표로 구분)
  * *기본값:* `Eps_e0.05,UCB_c0.05,SW_UCB_w100_c0.05,WSLS,Softmax_t0.1,DecayEps_e0.2,Eps_e0.1`
* **`-k` 또는 `--num_agents`** (int, 기본값: 8)
  * `density` 모드 전용 파라미터입니다. 시장에 투입할 총 인원수를 결정합니다. (예: 16, 32)
